In summary for tx_apdc_subset,

  1. How many records (rows) are there?
    145 records

  2. What is the unit or level of each record? That is, what does each observation/row represent. Is it one row per person or per something else?
    Each row represents a hospitalisation episode of care for one patient undergoing a kidney transplant.

  3. Which is the ID variable? How has this been stored?
    ‘ppn’ uniquely identifies each person. It is stored as a character string.

  4. Which variables are dates? Have these been formatted appropriately?
    ‘episode_start_date’ and ‘episode_end_date’ are date variables. They are both stored as characters so will need to be converted to dates.
